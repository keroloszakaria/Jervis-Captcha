# Jervis Captcha

A local Go/SQLite verification service and a framework-neutral TypeScript/Lit widget. The customer application keeps its existing frontend and backend technology.

**Current version: 0.1.0-alpha.1.** Functional integration candidate. No AI-proof or independently audited security claim.

Start with the [quick start](./quickstart.md), then implement the full [API cycle](./api.md). See [acceptance and remaining work](./roadmap.md) before production rollout.

The runtime works without cloud services, remote fonts, CDNs, telemetry or activation. Build-time dependency downloads are separate from deployment-time operation.
